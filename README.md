# Speaker Profile Manager

WordPress plugin for speaker profile management and Elementor Dynamic Tags.

## Version 1.1.0
- Speaker custom post type and fields.
- Featured Image used as speaker portrait.
- One company logo attachment reused for profile and marquee (recommended source size: 600 × 300 px).
- Elementor Dynamic Tags: Speaker Name, Speaker Title, Speaker Company, Speaker Ring Color, Speaker Company Logo.

## Update
Back up the site and current plugin folder, then replace the plugin files with this version. Existing `spm_speaker` posts and metadata are preserved. Do not delete speaker entries.

## Elementor
Use the **Speaker Company Logo** dynamic tag on an Image widget. Set image size to Full and Object Fit to Contain to preserve the logo ratio. Use the text tags for name, title, company, and ring color.

Elementor must be active for its dynamic tags to register. Elementor Pro is needed for Loop Grid.
